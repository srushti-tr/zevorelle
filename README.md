# Zevorelle – Anti Tarnish Jewellery India

A modern, SEO-optimized **static e-commerce website** created for **Zevorelle**, an online fashion jewellery brand offering premium **anti tarnish jewellery** across India.

> ✨ **Zevorelle specializes in waterproof, anti tarnish, skin-friendly, and long-lasting jewellery designed for everyday elegance.**

- **Brand:** Zevorelle
- **Website:** https://zevorelle.netlify.app/
- **Category:** Anti Tarnish Fashion Jewellery
- **Service Area:** Pan India
- **Primary Focus Cities:** Mumbai, Delhi, Gurgaon, Bangalore, Chennai, Hyderabad, Pune, Noida, Ahmedabad, Kolkata

# 🚀 Run Locally

No installation required.

Simply open:

```
index.html
```

or use Python:

```bash
python3 -m http.server 8000
```

Then visit:

```
http://localhost:8000
```
