Frequently Asked Questions

Everything students and visitors usually ask about this project.

Home › FAQ
Is Express Store By Kaushaindra a real shop?

No. This is a static demo built purely to teach Digital Marketing students practical SEO. No real orders, payments or deliveries happen on this site.

Can I fork this project for my own class?

Yes. It's built as an open learning resource — see README.md for setup instructions and CUSTOMIZATION.md for how to rebrand it.

What technologies were used to build this site?

Only HTML5, CSS3 and vanilla JavaScript. There's no framework, backend, database or build tool, so every line of code is easy to read and learn from.

Where can I see the SEO techniques used?

Every page includes HTML comments above each SEO tag explaining what it does. There's also a full SEO-CHECKLIST.md file documenting every technique used across the site.

Does the search and price sorting actually work?

Yes — the Shop page's search box, category filters and price sort are all powered by vanilla JavaScript running entirely in your browser (see js/main.js).

Who created this project?

Kaushaindra Kumar, a Digital Marketing trainer based in Rewari, Haryana, India, built this project as a teaching tool for practical SEO training.

Can I use the product images commercially?

The product photos are auto-generated placeholder graphics, used only to demonstrate image SEO (alt text, sizing, lazy loading) — swap them for your own images before using this for anything beyond learning.

Still have a question?

Reach out through the Contact page — this demo form won't send an email, but it shows how a real contact flow would be structured.
